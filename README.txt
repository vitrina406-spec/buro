БЮРО РЕСТОРАННИХ РІШЕНЬ — лендинг

Склад:
  index.html   — весь сайт (HTML, CSS, JS в одному файлі)
  img/         — логотип, фото, фото страв (img/food/)
  media/       — відео першого екрана і блоку «Дизайн-проєкт» (без звуку)

Як викласти:
  Завантажте папку цілком на будь-який хостинг (Netlify, Vercel, GitHub Pages
  або звичайний хостинг з доменом). Збірка не потрібна.
  Найшвидше: app.netlify.com/drop — перетягнути папку у вікно.

Що замінити перед запуском (пошук по index.html):
  [+380 XX XXX XX XX]   — телефон Дмитра
  https://t.me/         — посилання на Telegram Дмитра

Заявки (форми на сторінці і тест у попапі):
  На початку другого скрипта в index.html є змінна LEAD_ENDPOINT.
  Вкажіть там адресу обробника форм, наприклад:
    - Formspree (formspree.io) — пересилає заявки на пошту;
    - Make / n8n / Zapier webhook — може пересилати в Telegram-бот.
  Сайт надсилає POST із JSON: source, name, phone, way (як зв'язатися:
  Telegram, Viber, WhatsApp або Дзвінок), answers (відповіді тесту),
  estimate (розрахунок), page, sentAt.
  Токен Telegram-бота НЕ вставляйте прямо в index.html — його побачить будь-хто.

Попап із тестом:
  POPUP_EVERY_MS = 60000 — тест відкривається сам після кожної хвилини, поки людина
  гортає сайт (0 = вимкнути). Після того як людина залишила заявку, попап більше
  сам не з'являється.

Документи (політика конфіденційності й договір оферти):
  Відкриваються з підвалу сайту й з позначки згоди в кожній формі.
  Пряме посилання: ваш-домен/#privacy і ваш-домен/#oferta.
  У тексті жовтим підсвічено те, що треба заповнити: ПІБ ФОП або назва компанії,
  ІПН/ЄДРПОУ, адреса, email, телефон, IBAN, розмір авансу, місто.
  Шукайте в index.html фрагмент class="fill" і замініть текст у квадратних дужках.
  Тексти — шаблон; перед запуском їх варто показати юристу.
